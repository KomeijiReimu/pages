---
title: 主题目录与主笔记
---

一个笔记家族有一篇主笔记。读者打开家族目录，可以从主笔记开始，也可以直接选读从属笔记。家族成员按目录组织，无需逐篇添加标签或填写成员名单。

## 在私人笔记库中指定主笔记

把 `_family.md` 与主笔记放在同一目录。例如：

```text
notes/容器/docker/
├── _family.md
├── Docker 系统笔记.md
├── 操作速查.md
├── 基础/
│   └── 安装.md
└── 网络/
    └── 配置.md
```

在 `_family.md` 中写入：

```markdown
---
main: "Docker 系统笔记.md"
---

这里整理 Docker 的**基础概念**与实践记录。
```

`main` 填同目录下主笔记的实际文件名，含 `.md` 后缀，支持中文、空格和 `./` 前缀。目录页的链接显示笔记标题。`index.md`、`_index.md` 和 `_family.md` 不能作为主笔记。

分隔线下方是给读者看的家族简介，可以留空。用同一行内成对的 `**文字**` 加粗关键词。目录页保留段落换行；不会把简介当作完整 Markdown 文档渲染，HTML 标签也只显示为文字。

将 `_family.md` 和主笔记都纳入私人笔记库的同步范围，照常运行手动发布流程。`_family.md` 本身不生成文章，也不进入搜索、RSS、站点地图或别名重定向。它若标为 `draft: true`，该目录不显示家族入口。

## 从目录页阅读

发布后，打开示例目录 `/notes/容器/docker/`。说明卡先标出「这是一个笔记家族」，卡片下方依次是你填写的简介和阅读入口：

- **主笔记**直接打开《Docker 系统笔记》。主笔记在目录里只列一次。
- **从属笔记**跳到本页列表。读者可以直接点《操作速查》，也可以从「基础」「网络」分组打开深层笔记或进入子目录。
- 如果子目录也有自己的 `_family.md` 且已生效，上一级只链接到这个子家族的目录。只剩子目录可选时，第二个入口显示为「子目录」；只有主笔记时，页面只显示主笔记入口。

上一级目录会标记通往家族的链接，笔记页的面包屑也会标出所属的家族目录。`/categories/` 的「专题」只列 `notes/` 的一级目录：这个例子要先选「容器」，再进入 `docker`。

家族目录底部的评论用于讨论整个专题，各篇笔记保留自己的评论。若只想关闭家族目录的评论，在该目录的 `index.md` 中设置 `comments: false`。

## 检查家族是否生效

本机已有同步后的笔记时，在站点仓库根目录运行 `bun run preview`，打开 `http://localhost:8080/notes/容器/docker/`。若看不到家族入口，先检查两个文件是否都已同步、是否标为草稿，再核对 `main` 的文件名。主笔记改名后，也要更新 `main`。构建发现主笔记无效时会给出 `[document-family] Ignoring marker` 提示。
