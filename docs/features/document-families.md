---
title: 主题目录与主笔记
---

将一个主题目录设为笔记家族后，读者既可以从主笔记开始，也可以在目录页直接选读从属笔记。主笔记不必与目录同名。

## 添加主题标记

在自己的私人笔记库中，把 `_family.md` 放进对应的主题目录。例如：

```text
notes/容器/docker/
├── _family.md
├── Docker 系统笔记.md
├── 操作速查.md
├── 基础/
└── 网络/
```

`_family.md` 的内容：

```markdown
---
main: "Docker 系统笔记.md"
---

这里整理 Docker 的基础概念与实践记录。
```

`main` 必须是**同一目录中、已发布的普通 `.md` 文件名**。支持中文、空格和可选的 `./` 前缀，例如 `main: "./Docker 系统笔记.md"`。目录页按这个文件名找到主笔记，链接上显示的则是笔记标题。

## 读者会看到什么

家族目录页的卡片先说明「这是一个笔记家族」以及如何选读。你写在 `_family.md` 里的简介单独排在卡片下方；不写简介就直接显示阅读入口。

- **主笔记**直达指定文章。**从属笔记**跳到本页列表，按所在目录分组，深层笔记也能直接打开。只有主笔记的家族不显示空列表。
- 如果子目录也是独立家族，上一级只提供通往它的目录链接，不把两个家族的成员混排。
- 读者从「专题」、上一级目录或文章面包屑进入时，可以通过「笔记家族」标识认出家族入口。

## 简介与发布规则

- 标记正文是可选的纯文本简介，可以留空；正常段落换行会保留。
- 不要依赖 Markdown 或 HTML 排版：简介不转换成富文本，HTML 只作为文字显示。
- `_family.md` 是构建元数据，不会成为公开文章，也不会进入搜索索引、RSS、站点地图或别名重定向。
- 主笔记仍作为普通文章发布，不会在它自己的从属笔记列表中重复出现。
- 主笔记不能是 `_family.md`、`index.md` 或目录索引 `_index.md`，不能是外链、父目录文件或子目录文件。
- 未填写有效 `main`、目标不存在或被草稿/忽略规则排除时，构建会告警，目录不显示主笔记提示，不生成死链接。
- 草稿标记本身不生效。YAML 语法错误沿用现有解析器的报错方式。
- 只有放置了有效标记的目录才有家族说明卡。成员按发布后的目录结构列出，不需要另填名单。

新增、修改或删除标记，以及修改主笔记标题、删除主笔记或将其改为草稿后，开发预览会刷新受影响的目录提示。

在自己的私人主题笔记目录维护此文件即可；无需把个人笔记提交到站点代码仓库。
