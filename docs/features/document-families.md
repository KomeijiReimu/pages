---
title: 主题目录与主笔记
---

主题目录可以保留原有笔记和子目录列表，同时提示读者前往一篇主笔记。无需增加插件配置，也不要求主笔记与目录同名。

## 添加主题标记

在自己的私人笔记库中，把 `_family.md` 放进对应的主题目录。例如：

```text
notes/容器/docker/
├── _family.md
├── Docker 系统笔记.md
├── 操作速查.md
├── 基础/
└── 网络/
```

`_family.md` 的内容：

```markdown
---
main: "Docker 系统笔记.md"
---

这里整理 Docker 的基础概念与实践记录。

需要完整阅读时，请从主笔记开始。
```

`main` 必须是**同一目录中、已发布的普通 `.md` 文件名**。支持中文、空格和可选的 `./` 前缀，例如 `main: "./Docker 系统笔记.md"`。匹配的是文件路径，不是笔记标题；按钮显示主笔记的实际标题。

## 简介与发布规则

- 标记正文是可选的纯文本简介，可以留空；正常段落换行会保留。
- 不要依赖 Markdown 或 HTML 排版：简介不转换成富文本，HTML 只作为文字显示。
- `_family.md` 是构建元数据，不会成为公开文章，也不会进入搜索索引、RSS、站点地图或别名重定向。
- 主笔记仍作为普通页面发布，目录中的其他笔记和子目录继续照常列出。
- 主笔记不能是 `_family.md`、`index.md` 或目录索引 `_index.md`，不能是外链、父目录文件或子目录文件。
- 未填写有效 `main`、目标不存在或被草稿/忽略规则排除时，构建会告警，目录不显示主笔记提示，不生成死链接。
- 草稿标记本身不生效。YAML 语法错误沿用现有解析器的报错方式。
- 标记仅作用于所在目录，不会向父目录或子目录继承，也不会分类成员或孤儿笔记。

新增、修改或删除标记，以及修改主笔记标题、删除主笔记或将其改为草稿后，开发预览会刷新受影响的目录提示。

在自己的私人主题笔记目录维护此文件即可；无需把个人笔记提交到站点代码仓库。
